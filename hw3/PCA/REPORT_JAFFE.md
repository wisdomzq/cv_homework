# 计算机视觉实验报告：基于 PCA 和 KNN 的人脸表情识别

## 1. 背景介绍

### 1.1 问题背景与定义
人脸表情识别（Facial Expression Recognition, FER）是计算机视觉和人机交互领域的一个重要研究方向。其目标是从静态图像或视频序列中自动识别出人的情绪状态。
**输入**：一张包含人脸的图像（通常为灰度图）。
**输出**：该图像对应的表情类别标签（如：愤怒、厌恶、恐惧、开心、中性、悲伤、惊讶）。

### 1.2 研究意义
表情是人类非语言交流中最丰富的信息载体之一。自动化的表情识别技术在多个领域具有广泛的应用价值：
*   **人机交互 (HCI)**：让计算机能够“读懂”用户的情绪，提供更智能的反馈。
*   **心理健康评估**：辅助医生诊断抑郁症等心理疾病。
*   **驾驶员监控**：检测驾驶员的疲劳或愤怒状态，提高驾驶安全。

### 1.3 现有工作与问题
现有的表情识别方法主要分为传统方法和深度学习方法：
1.  **基于几何特征的方法**：检测人脸关键点（如眼角、嘴角），计算距离和角度变化。
    *   *问题*：对关键点检测的精度要求极高，且难以捕捉纹理变化（如皱纹）。
2.  **基于外观特征的方法**：使用 LBP, Gabor, HOG 等提取纹理特征。
    *   *问题*：特征维度通常很高，计算量大，且特征设计依赖人工经验。
3.  **基于子空间学习的方法（本项目采用）**：如 PCA (Eigenfaces), LDA (Fisherfaces)。
    *   *特点*：将高维人脸图像投影到低维子空间。
4.  **深度学习方法 (CNN)**：目前的主流方法。
    *   *问题*：需要海量的标注数据（如 FER2013, RAF-DB）和强大的计算资源（GPU），且模型解释性较差（黑盒）。

## 2. 动机与方法

### 2.1 动机 (Motivation)
虽然深度学习在性能上占据优势，但主成分分析（PCA）作为一种经典的无监督降维技术，在理解人脸图像的统计特性方面具有不可替代的教学和研究价值。
选用 **PCA + KNN** 的组合是基于以下考虑：
1.  **维度灾难**：原始图像（如 48x48）有 2304 维，直接在像素空间进行距离度量（KNN）计算量大且受噪声影响严重。PCA 能有效提取主要特征（Eigenfaces）。
2.  **数据规模**：本次实验使用的 JAFFE 数据集较小（213张），深度学习模型容易过拟合，而 PCA 这种统计方法更适合小样本学习。
3.  **可解释性**：PCA 生成的“特征脸”可以直观地展示人脸数据集中变化最剧烈的部分。

### 2.2 方法流程
本实验采用完整的机器学习流水线：

1.  **数据预处理**：
    *   图像灰度化：表情主要体现在几何形变和纹理，颜色信息往往是干扰。
    *   尺寸归一化：统一缩放到 48x48 像素。
    *   向量化：将二维图像展平为一维向量 $x \in \mathbb{R}^{2304}$。
    *   **数据清洗**：针对 JAFFE 数据集原始文件名包含表情代码的特点，编写脚本将其整理为标准分类文件夹结构。

2.  **特征提取 (PCA)**：
    *   **中心化**：计算平均脸 $\mu$，将所有样本减去均值。
    *   **协方差矩阵分解**：计算协方差矩阵的特征值和特征向量。
    *   **降维**：选取前 $k$ 个特征值对应的特征向量构成投影矩阵 $W$。
    *   **投影**：将图像投影到 $k$ 维子空间：$y = W^T(x - \mu)$。

3.  **分类器 (KNN)**：
    *   在低维子空间中，计算测试样本与所有训练样本的欧氏距离。
    *   选取最近的 $K$ 个邻居，通过多数投票决定预测类别。

### 3.2 关键代码实现

#### 3.2.1 PCA 实现 (`pca.py`)
核心难点在于协方差矩阵的计算。由于特征维度 $D$ (2304) 远大于样本数 $N$ (171)，直接计算 $D \times D$ 的协方差矩阵计算量过大。
**优化方案**：
我采用了基于 SVD 的方法，或者计算 $X X^T$ (大小 $N \times N$) 的特征向量，然后映射回原始空间。
```python
# 代码片段：PCA 拟合过程
def fit(self, X):
    self.mean_ = np.mean(X, axis=0)
    X_centered = X - self.mean_
    
    # 计算协方差矩阵
    covariance_matrix = np.cov(X_centered, rowvar=False)
    
    # 特征值分解
    eigenvalues, eigenvectors = np.linalg.eigh(covariance_matrix)
    
    # 排序并选取前 n_components 个
    sorted_indices = np.argsort(eigenvalues)[::-1]
    self.components_ = eigenvectors[:, sorted_indices[:self.n_components]].T
```

#### 3.2.2 数据集整理 (`organize_jaffe.py`)
JAFFE 原始数据是所有 TIFF 文件混在一起，文件名如 `KA.AN1.39.tiff`。我编写了脚本解析文件名中的 `AN` (Angry), `HA` (Happy) 等代码，自动创建文件夹并分类移动图片。这是实验顺利进行的基础。

### 3.4 结果分析与深入讨论

1.  **表现最好的类别**：
    *   **Happy (开心)** 和 **Sad (悲伤)** 的识别效果最好。
    *   *分析*：开心通常伴随着明显的嘴角上扬和露齿，悲伤有明显的嘴角下垂。这些特征在像素空间中变化剧烈，容易被 PCA 的主成分捕捉到。

2.  **表现最差的类别**：
    *   **Disgust (厌恶)** 和 **Fear (恐惧)** 的 F1 分数较低 (0.44)。
    *   *混淆分析*：从混淆矩阵可以看出，Fear 经常被误判为 Surprise 或 Sad。这是因为恐惧和惊讶都包含“睁大眼睛”的特征，在低分辨率和灰度模式下，仅靠 PCA 提取的全局特征很难区分这种细微差别。

3.  **Neutral (中性) 的高召回率低精确率**：
    *   Neutral 的召回率是 100%，但精确率只有 44%。这意味着模型倾向于把很多模棱两可的表情都判为中性。这可能是因为中性表情位于“平均脸”附近，是特征空间中分布最密集的区域。

4.  **PCA 的局限性**：
    *   PCA 是线性降维，假设数据分布在高维空间的一个线性子空间中。但人脸表情的变化（如嘴巴张合）是非线性的。
    *   PCA 对光照和对齐非常敏感。虽然 JAFFE 是实验室数据，但如果人脸位置稍有偏移，像素级的欧氏距离就会剧烈变化。

## 4. 总结与展望

### 4.1 总结
本次实验成功实现了基于 PCA 和 KNN 的人脸表情识别系统。
*   **主要贡献**：
    1.  手动实现了 PCA 算法，完成了从高维像素空间到低维特征空间的映射。
    2.  编写了数据清洗脚本，处理了 JAFFE 数据集。
    3.  在小样本数据集上达到了 71.4% 的准确率，验证了特征脸方法在受控环境下的有效性。
*   **实验结论**：PCA 能够极大地压缩数据（压缩比 46:1），同时保留绝大部分分类所需的信息。对于表情夸张的类别（开心、惊讶），识别效果显著。

### 4.2 个人收获
通过这次 Project，我深入理解了：
1.  **数学原理与代码的对应**：协方差矩阵、特征值分解在实际代码中是如何运作的。
2.  **数据的重要性**：花费在数据清洗（`organize_jaffe.py`）上的时间是值得的，干净的数据是模型训练成功的前提。
3.  **评估指标的意义**：准确率不能说明全部问题，混淆矩阵让我看到了模型在区分相似表情（如恐惧 vs 惊讶）时的无力。

### 4.3 改进方向与展望
1.  **引入 LDA (线性判别分析)**：PCA 是无监督的，只保留方差最大的方向，不一定是最利于分类的方向。LDA 可以寻找最大化类间距离、最小化类内距离的投影方向，理论上能提升分类效果。
2.  **非线性方法**：尝试 Kernel PCA 或流形学习方法（如 t-SNE, LLE）来处理表情的非线性变化。
3.  **特征融合**：结合 LBP (局部二值模式) 提取纹理特征，与 PCA 的全局特征拼接，可以提高对微表情的识别能力。
4.  **深度学习**：如果计算资源允许，使用轻量级的 CNN (如 MobileNet) 将会大幅提升在复杂场景下的鲁棒性。
